# Session-Aware Intent & Anomaly Detection for Enterprise AI Query Telemetry
## Setup Instructions
1. Clone this repository
2. Use pip to install the following modules:
   - jupyter
   - pandas
   - numpy
   - matplotlib
   - seaborn
   - sklearn
   - keras
3. Run ```jupyter notebook notebooks``` to read both notebooks.\
